# 造境工坊

### 灵感有了，就去造境。

用 AI 生成图片、创作视频、合成语音与音乐。也可以把这些能力接入 WorkBuddy，让 AI 助手帮你完成创作。

[开始创作](https://cc.oozoo.cc/) · [快速开始](https://cc.oozoo.cc/developer/docs) · [模型与接口文档](https://cc.oozoo.cc/developer/docs/diffusion-models)

## 从一句话开始

在 WorkBuddy 中提出创作需求，让它通过造境工坊完成生成、查询进度和获取结果。

> 请用造境工坊生成一张图，一只橘猫坐在窗边晒太阳，温暖的午后光线。

> 请用造境工坊把这段文字合成为语音，声音自然、清晰。

> 请用造境工坊创作一段轻快的音乐，适合作为旅行视频的背景。

## 你可以做什么

| 能力 | 可以尝试的创作 |
| --- | --- |
| 文生图 | 把文字描述变成插画、海报素材或场景图片 |
| 参考图生成 | 上传参考图片，结合提示词生成新的画面 |
| 视频生成 | 从文字或图片出发生成视频，尝试参考视频与遮罩编辑 |
| 文本转语音 | 把文案、对白和文章转换成语音 |
| 个人音色 | 使用参考录音制作个人音色，再用该音色合成语音 |
| 语音转文本 | 将录音转换成文字 |
| 音乐与歌曲 | 根据风格和歌词创作音乐，尝试翻唱与改词 |
| 图片理解 | 识别图片文字、理解画面内容、比较两张图片 |
| 目标检测 | 找出图片中的目标，获取标注图片和检测框 |

语音转文本的「区分说话人」功能目前处于调试阶段，多人录音的编号准确性仍在验证。

## 在网页里创作

登录造境工坊，进入「我的任务」，点击「发起任务」，选择可用模型并填写创作内容。提交后可以在任务列表查看排队状态、执行进度和生成结果。

你也可以管理个人音色，在造境广场浏览与分享作品、提示词和生成参数。

[打开造境工坊](https://cc.oozoo.cc/)

## 交给 WorkBuddy

1. 把下方提示词发送给 WorkBuddy，让它阅读接入文档。
2. 注册造境工坊账号，在控制台创建 API Key，并按 WorkBuddy 的指引安全配置。
3. 告诉 WorkBuddy 你想生成什么。
4. 在 WorkBuddy 或造境工坊「我的任务」中查看结果。

```text
请帮我接入造境工坊。先阅读接入文档：
https://cc.oozoo.cc/developer/docs

读完后，告诉我如何安全配置 API Key。
等我发出创作指令，再按文档提交任务、查询进度并展示结果。
```

## 接入你的应用

造境工坊提供统一的异步任务 API，将生成能力接入自己的工具或工作流。

- 使用 API Key 认证。
- 提交任务后，通过任务编号查询状态并获取结果。
- 图像、视频、语音、音乐与图片理解等能力使用统一任务流程。
- 控制台汇总网页和 API 发起的任务，便于查看进度与历史结果。

文本模型另提供兼容接口，具体协议和可用模型见文档。

## 模型一览

| 方向 | 模型 |
| --- | --- |
| 图像 | Z-Image Turbo、FLUX.2 Klein 4B |
| 视频 | Wan2.1 VACE 1.3B、Wan2.1 T2V 1.3B、CogVideoX1.5 5B I2V |
| 语音识别 | SenseVoiceSmall |
| 语音合成与个人音色 | Qwen3-TTS 0.6B、CosyVoice3 0.5B |
| 音乐 | ACE-Step v1 3.5B、ACE-Step 1.5 Turbo、YuE2 3B GGUF |
| 图片理解与检测 | Qwen3-VL 4B Instruct、YOLO11n |
| 文本 | V4 Flash、V4 Pro |

各账号可使用的模型以控制台展示为准，最新参数和能力范围见接口文档。
